**What changed & why:** The current-ratio value sub-factor is now only added when the stock’s preliminary value score (from all other value components) is below 60. This prevents the sub-factor from over-rewarding already-cheap large-caps, which previously hurt 1-month Spearman ρ while still preserving the 3-month and 6-month gains observed from the earlier current-ratio addition.
